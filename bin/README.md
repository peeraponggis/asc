## กู้คืน

```bash
git mv bin/ชื่อไฟล์ ./
```

ถ้าเป็นไฟล์เว็บที่ต้องขึ้นเว็บจริงด้วย ต้องเพิ่มชื่อในรายการของ `sync-docs.cmd` แล้วรันสคริปต์นั้นก่อน commit

## ก่อนลบทิ้งถาวร

ทุกไฟล์ยังอยู่ในประวัติ git อยู่แล้ว (ยกเว้น `master_shellOLD.html` ที่ไม่เคยถูก track)
ถ้าจะลบจริง ให้สำรอง `master_shellOLD.html` ออกไปไว้ที่อื่นก่อน เพราะลบแล้วหายเลย
