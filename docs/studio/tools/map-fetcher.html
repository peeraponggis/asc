1 รับภาพ

Google Maps — เปิดแท็บ Maps · กดเข็มทิศให้ทิศเหนือขึ้นบน (หรือกด r) · ปิดแผงข้าง · แล้วกด "จับภาพแท็บ" และเลือกเป็น "แท็บ Chrome" ไม่ใช่หน้าต่างหรือทั้งหน้าจอ
Google Earth Pro — กด u (มองตรงลงล่าง) แล้ว n (ทิศเหนือขึ้นบน) → Win+Shift+S คัดลอกภาพ → กลับมากด "วางจากคลิปบอร์ด"

3 กำหนดพิกัด

📏 สเกลบาร์ — จำเป็นเฉพาะเมื่อ URL เป็นแบบ …z (มุมมองแผนที่)
มุมมองดาวเทียม URL จะเป็นแบบ …m ซึ่งบอกสเกลมาตรง ๆ ไม่ต้องลาก · ลากไว้ก็ได้ ระบบจะใช้ตรวจไขว้ให้
เลือกเครื่องมือ 📍 ปักจุดอ้างอิง แล้วคลิกบนภาพ จากนั้นวางพิกัดของจุดนั้น
Maps: คลิกขวาที่จุดนั้น → คลิกบรรทัดพิกัดเพื่อคัดลอก · Earth Pro: อ่านแถบสถานะด้านล่าง

4 ผลลัพธ์ & บันทึก

1 รับภาพแปลงที่ดินจาก landsmaps

ที่ landsmaps.dol.go.th ค้นแปลงจากเลขโฉนด/ระวาง → เปิดชั้น "รูปแปลงที่ดิน" ให้เห็นเส้นขอบแปลงสีแดง → บันทึกภาพหน้าจอ (Win+Shift+S) → กลับมากด วางจากคลิปบอร์ด หรือเลือกไฟล์ภาพ
ภาพควรเห็นจุดสังเกตร่วมกับภาพดาวเทียม (หัวมุมถนน มุมรั้ว มุมแปลงข้างเคียง) อย่างน้อย 2–3 จุด เพื่อใช้ปักจุดอ้างอิง

3 พิกัดของจุดอ้างอิง

— ไม่ต้องเปิด Google Maps ไม่ต้องพิมพ์พิกัด
คลิกจุดเดียวกันบนภาพโฉนดและภาพดาวเทียมที่มี world file แล้ว โปรแกรมอ่านพิกัดให้เอง
หรือพิมพ์พิกัดจริงของแต่ละจุดเอง — รับทั้ง lat, lng (เช่น 16.4628994, 102.8242508) และ UTM WGS84 (เช่น 47N 262000 1820000 หรือ zone 48 512345 1655000)
หาพิกัดได้จาก Google Maps (คลิกขวา → คลิกบรรทัดพิกัดเพื่อคัดลอก) ที่จุดสังเกตเดียวกันกับที่ปักบนภาพโฉนด
