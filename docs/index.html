ย้ายโครงการเดิมขึ้นคลาวด์

ยังไม่ได้ย้าย

พบโครงการที่ยังเก็บอยู่ในเบราว์เซอร์เครื่องนี้ ซึ่งคนอื่นมองไม่เห็นและจะหายถ้าล้างข้อมูลเบราว์เซอร์
การส่งขึ้นคลาวด์จะคัดลอกขึ้นไปเป็นโครงการใหม่ ของเดิมในเครื่องยังอยู่ครบ ตรวจสอบแล้วค่อยลบเองภายหลัง

จัดการผู้ใช้

ADMIN

เพิ่ม แก้รหัสผ่าน หรือระงับบัญชีได้จากที่นี่ ผู้ใช้ที่เพิ่มจะใช้ล็อกอินได้ทันทีบนเครื่องนี้ แต่จะยังไม่มีผลกับเครื่องอื่น จนกว่าจะกดสร้างไฟล์ user.js ฉบับใหม่แล้วอัปโหลดขึ้น GitHub

ชื่อผู้ใช้ รหัสผ่าน สิทธิ์ ที่มา จัดการ

ทำให้มีผลกับทุกเครื่อง: กดปุ่มด้านล่างเพื่อดาวน์โหลด user.js ฉบับรวมผู้ใช้ล่าสุด แล้วนำไปวางทับไฟล์เดิมใน repo asc บน GitHub แล้ว commit

การตั้งค่าอื่น

รอพัฒนา
  • เปลี่ยนรหัสผ่านด้วยตนเอง
  • ค่ามาตรฐานโครงการ (ยี่ห้อแผง อินเวอร์เตอร์ ค่าไฟฟ้าต่อหน่วย)
  • โลโก้และหัวกระดาษบนรายงาน
  • ซิงก์ข้อมูลขึ้นคลาวด์อัตโนมัติ
