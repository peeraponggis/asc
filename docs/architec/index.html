ภาพรวม

ชุดเครื่องมือเขียนแบบฟรีแทน AutoCAD + SketchUp — ต่อกับ ASC Studio และ ASC Cloud

✏️ เปิดตัวเขียนแบบ — วาดผัง 2D → 3D → Render 📐 CAD 2D — เปิด/แก้/บันทึก DWG · DXF

ขั้นตอนงานโซลาร์รูฟท็อป

  1. ASC Studio วางแผง → ส่งออกทั้งหมด (ได้ 3d.glb · roof_*.dxf · SLD ร่าง)
  2. โครงการ → นำเข้างาน ASC Studio มาเป็นโครงการ (ไฟล์ทั้งหมดอยู่ในโฟลเดอร์เดียว)
  3. ผลผลิตไฟฟ้า → คำนวณด้วย pvlib จากแคช PVGIS เดียวกับ ASC Studio → ได้ไฟล์ส่ง ASC
  4. แม่แบบ & โปรแกรม → เปิด DXF ใน CadCraft · render ภาพด้วย Blender · วาด SLD ใน QElectroTech

โครงการ

ASC Studio — ทุกโฟลเดอร์

งานออกแบบ → นำเข้า เป็นโครงการ (3D · ผัง · ภาพดาวเทียม · หลังคา · SLD · เอกสาร) · DXF/DWG → CAD 2D เปิดดู/แก้ (บันทึกเป็นสำเนา ไม่แก้ไฟล์ของ ASC Studio) · ไฟล์อื่น → ดู

สร้างโครงการเปล่า

โครงการทั้งหมด

รุ่นออนไลน์เก็บโครงการเป็นไฟล์ JSON — กด บันทึกไฟล์โครงการ ในแท็บผลผลิตไฟฟ้า แล้วนำไปเปิดในรุ่นในเครื่องได้

ประมาณการผลิตไฟฟ้า

รุ่นออนไลน์คำนวณ pvlib ไม่ได้ (ต้องใช้ Python ในเครื่อง) — ใช้ผลผลิตไฟฟ้าใน ASC Studio รุ่นคลาวด์ หรือเปิด pee_architec ในเครื่อง

QElectroTech

สัญลักษณ์ SLD แบบไทย 47 ตัวเป็น element ของ QElectroTech: โฟลเดอร์ qelectrotech\custom_elements\pee_architec\

วิธีใช้: QElectroTech › Settings › Configure › Paths → ชี้ "custom elements" มาที่โฟลเดอร์ qelectrotech\custom_elements

Blender

สคริปต์ setup_scene.py — สร้างฉาก render จาก 3d.glb ของ ASC Studio (ท้องฟ้า · ดวงอาทิตย์ · กล้อง · พื้น) หรือสร้างแม่แบบบ้าน/โรงงาน

blender -b -P blender\setup_scene.py -- --template house --save 3d_models\templates\house_template.blend
